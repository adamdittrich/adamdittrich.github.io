FOR THE EXISTING LIVE REPOSITORY:
1. Open the repository adamdittrich.github.io on GitHub, on the Code tab.
2. Choose Add file > Upload files.
3. Upload the CONTENTS of the update folder (not the ZIP or enclosing folder).
4. Keep the assets folder structure. Commit directly to main.
5. Wait for Publish Quarto website in Actions to finish, then refresh the site.

The existing publishing workflow does not need to be changed.
GitHub runs Quarto automatically. There is no need to install it locally.

The separate full source package includes the working workflow for backup or a
fresh installation. Source pages are .qmd files; docs is generated output.
