# Archived original v0.6 implementation

These Python files and requirements are copied unchanged from the recovered
v0.6 research release. They preserve methods, acquisition URLs and original
validation logic. They are not the builder for the public-edition file layout.

Read [SOURCE_RECONSTRUCTION.md](../../docs/SOURCE_RECONSTRUCTION.md) for input
requirements. Some scripts require the exact archived v0.5 base and original
working paths. The original railway chronology predates the separately supplied
v0.6.1 correction. Historical wording in generated documentation describes that
older private research handover; current public terms are in
[SOURCES_AND_REUSE.md](../../docs/SOURCES_AND_REUSE.md).

Source data are not bundled here. The original project code's MIT licence does
not replace any provider's data licence.
